# Portfolio, Resume, And Interview Packaging

## Portfolio Case Study

### Title

SmartExamPrep: An AI-Powered Adaptive Learning Platform for GATE CSE

### Short Case Study

SmartExamPrep is a full-stack adaptive exam preparation system built for GATE CSE. I designed it to move beyond static question banks by combining topic-level weakness detection, adaptive quiz recommendation, spaced revision scheduling, and AI-assisted explanations. The system includes both a student workflow and an admin workflow for managing syllabus structure, question quality, scraping, and content ingestion.

The product is built with Next.js 14, TypeScript, Tailwind CSS, ShadCN UI, FastAPI, SQLAlchemy, PostgreSQL, and Python ML modules. I also integrated a workload-aware OpenRouter and Groq AI layer for weakness explanation and syllabus/question parsing. To make the system evaluation-ready, I added persistent result snapshots, analytics endpoints, demo personas, and feedback collection so learning improvement can be measured instead of only described.

## Interview Explanation

SmartExamPrep is a full-stack adaptive learning platform I built for GATE CSE preparation. The key idea was to move from static practice to performance-aware learning. After a student takes a diagnostic quiz, the system updates topic-level mastery and weakness scores, generates a readiness snapshot, recommends focused adaptive quizzes, and schedules future revision using spaced repetition. On the admin side, I built content CRUD, verification, scraping, and syllabus ingestion tools so the platform could actually be operated, not just prototyped. I also added analytics and research packaging so learning improvement could be measured over time.

## Concise “Tell Me About Your Project” Answer
