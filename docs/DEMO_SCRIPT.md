# Demo Script

Use this for a 2 to 3 minute demo video or live walkthrough.

## Screenshot Checklist

- Login page
- Student dashboard with readiness score
- Diagnostic quiz in progress
- Result page with topic comparisons
- Revision plan page
- Adaptive quiz page with weak-topic badges
- Admin dashboard
- Admin subjects page
- Admin questions page
- Scraper page
- Syllabus upload page
- Feedback page

## Best Demo Order

1. Problem statement
2. Student onboarding
3. Diagnostic quiz
4. Result analysis
5. Dashboard and adaptive recommendations
6. Revision plan
7. Admin content and ingestion
8. Research and analytics angle

## Tight 2-3 Minute Script

### 0:00 to 0:20

"SmartExamPrep is an AI-powered adaptive exam preparation platform for GATE CSE. Instead of giving every student the same question flow, it detects weak topics, recommends focused quizzes, and schedules revisions based on performance."

### 0:20 to 0:45

Show login, onboarding, and diagnostic quiz.

"A student registers, sets study preferences, and takes a diagnostic quiz across core GATE CSE topics."

### 0:45 to 1:10

Show result page and dashboard.

"After submission, the platform computes topic-level weakness, stores a persistent result snapshot, and updates the dashboard with readiness score, strongest topics, weakest topics, and subject progress."

### 1:10 to 1:35

Show adaptive quiz and revision page.

"The next quiz is adaptive. It prioritizes weaker topics and avoids recent duplicates. The revision planner then schedules due topics using spaced repetition logic."

### 1:35 to 2:00

Show admin pages.

"Admins can manage subjects, topics, and questions, verify imported content, run scraper jobs, and upload syllabi for automatic parsing."

### 2:00 to 2:25

Show analytics and feedback angle.

"The system also tracks research-ready metrics such as baseline score, adaptive improvement, revision compliance, and readiness trend. Students can submit structured feedback directly inside the app."

### 2:25 to 2:45

Close with architecture.

"The stack uses Next.js 14, FastAPI, PostgreSQL, SQLAlchemy, ML-based weakness detection and recommendation modules, plus a workload-aware OpenRouter and Groq AI layer for explanation and parsing tasks."
